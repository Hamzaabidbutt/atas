System requirements

What you need to run it

ATAS is a native Windows application. Order flow is data-hungry — the tick history behind a cluster chart is much larger than candle data, so give it memory and a fast disk.

  • Windows 10 or 11, 64-bit
  • 8 GB RAM minimum, 16 GB recommended
  • SSD with 10 GB free for tick history
  • A stable connection — latency matters more than bandwidth
  • macOS and Linux: run it on a Windows VPS or VM

After install

Common first questions

Do I have to pay to try the order-flow tools?

No. Activate the 14-day trial from inside the platform and every paid feature unlocks. When it ends you fall back to the free START plan rather than losing access entirely.

Can I run it on a Mac?

Not natively. Most Mac and Linux traders run ATAS on a Windows VPS close to the exchange, which also removes their home connection from the latency path.

Why does it need so much disk space?

Cluster charts are built from tick data, not candles. The platform caches that history locally so redrawing a footprint over a long session stays instant.

Can I use the same licence on two machines?

The licence is tied to your account, so you can sign in from a second machine — just not run both simultaneously on a single-seat plan.
